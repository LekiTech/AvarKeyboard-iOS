# Avar Keyboard 1.0.0 (build 2) — App Store release notes

## English

Choose how you type: Avar Keyboard now offers two layouts.

- 3-row — the compact classic: ъ and ӏ as direct keys, every digraph
  one long-press away
- 4-row — a dedicated top row with the Avar digraphs
  (гъ, хъ, къ, кӏ, тӏ, цӏ, чӏ, хӏ, гӏ, кь, хь) plus лъ and гь keys

Long-press works in both layouts, and the keyboard remembers your
choice.

Switch anytime: keyboard settings (gear key) → Хъвай → Раскладка.

## Русский

Выбирайте, как печатать: в аварской клавиатуре теперь две раскладки.

- 3 ряда — компактная классика: ъ и ӏ — отдельные клавиши, все
  диграфы — через долгое нажатие
- 4 ряда — отдельный верхний ряд с аварскими диграфами
  (гъ, хъ, къ, кӏ, тӏ, цӏ, чӏ, хӏ, гӏ, кь, хь) и клавиши лъ и гь

Долгое нажатие работает в обеих раскладках, а выбранная раскладка
запоминается.

Переключение: настройки клавиатуры (шестерёнка) → Хъвай → Раскладка.
