# Avar Keyboard 1.0.0 (build 2) — App Store release notes

## English

Choose how you type: Avar Keyboard now offers two layouts.

- 3-row — the classic compact layout
- 4-row — adds a dedicated top row with the Avar digraphs
  (гъ, хъ, къ, кӀ, тӀ, цӀ, чӀ, хӀ, гӀ, кь, хь)

The 4-row layout keeps every key of the 3-row layout exactly where it
was — it simply adds the digraph row on top, so your muscle memory
carries over. Long-press still works for every digraph and special
letter in both layouts, and the keyboard remembers your choice.

Switch anytime: keyboard settings (gear key) → Хъвай → Раскладка.

## Русский

Выбирайте, как печатать: в аварской клавиатуре теперь две раскладки.

- 3 ряда — классическая компактная раскладка
- 4 ряда — добавляет отдельный верхний ряд с аварскими диграфами
  (гъ, хъ, къ, кӀ, тӀ, цӀ, чӀ, хӀ, гӀ, кь, хь)

В 4-рядной раскладке все клавиши 3-рядной остаются ровно на своих
местах — сверху просто появляется ряд диграфов, поэтому привычка
набора полностью сохраняется. Долгое нажатие по-прежнему работает для
всех диграфов и особых букв в обеих раскладках, а выбранная раскладка
запоминается.

Переключение: настройки клавиатуры (шестерёнка) → Хъвай → Раскладка.
